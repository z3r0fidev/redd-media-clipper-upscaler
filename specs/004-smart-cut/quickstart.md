# Quickstart: validating Smart Cut

**Feature**: [spec.md](./spec.md) | **Contracts**: [contracts/](./contracts/)

## Prerequisites

- A workspace build with the bundled engine staged: `cargo xtask fetch-tools`, then
  `cargo build --workspace` (see `CLAUDE.md` for `fetch-ncnn`).
- The test fixtures are generated by `rmedia-testkit` (no binary fixtures in git).

## Automated checks (each maps to a success criterion)

| Check | Command | Expected |
|---|---|---|
| Frame-exact ends, eligible set (SC-001) | `cargo test -p rmedia-core --test smart_us1` | every clip starts and ends within one frame (mp4, mov, mkv, ts; with and without B-frames and audio) |
| Copied share (SC-002) | same suite, `long_clips_copy_most_frames` | ≥ 80% of frames copied for clips ≥ 10 GOPs |
| Seams (SC-003) | same suite, `seams_decode_cleanly` | 0 decode errors; pts steady across seams; audio within 20 ms of video at each seam |
| Fallbacks (SC-004) | `cargo test -p rmedia-core --test smart_us2` | each risky fixture is cut in accurate mode with its expected `fallback` value |
| Speed (SC-005) | `cargo test -p rmedia-core --test bench -- --ignored smart_vs_accurate` | smart ≤ ⅓ of accurate mode's time for a 60 s range of the 1080p fixture |
| Quality (SC-006) | `smart_us1::reencoded_parts_match_accurate_quality` | head and tail VMAF ≥ accurate mode's for the same frames; copied frames framemd5-identical |
| Cancel (SC-008) | `cargo test -p rmedia-core --test cancel smart` | stopped within 2 s at each stage; no `.part`, scratch or process left |
| Manifests and parity (SC-009) | `cargo test -p rmedia-core --test us3_batch smart` and desktop `cargo test --test bridge smart` | 0.3.0 manifests unchanged; JSON = CSV = desktop outputs |

## Manual run

```sh
# A source with mid-GOP range ends (2 s GOPs).
ffmpeg -f lavfi -i testsrc2=s=1280x720:r=25:d=30 -f lavfi -i sine=d=30 \
  -c:v libx264 -x264-params keyint=50:min-keyint=50:scenecut=0:bframes=3 -pix_fmt yuv420p \
  -c:a aac -shortest /tmp/src.mp4

rmedia clip /tmp/src.mp4 --start 3.32 --end 20.72 --mode smart --dry-run
#   smart: head 0.680 s (17 fr) re-encoded · copy 16.000 s (400 fr) · tail 0.720 s (18 fr) re-encoded · 92% copied

rmedia clip /tmp/src.mp4 --start 3.32 --end 20.72 --mode smart --json | jq -c 'select(.type=="job_finished") | .outcome.smart'
#   {"mode_used":"smart","copied_frames":400,"reencoded_frames":35,"copied_share":0.9195,"fallback":null}

ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=nb_read_frames -of csv=p=0 <output>
#   435
ffmpeg -v error -i <output> -f null -     # prints nothing
```

A fallback:

```sh
ffmpeg -f lavfi -i testsrc2=s=1280x720:r=25:d=10 -c:v libx264 \
  -x264-params keyint=50:bframes=3:open-gop=1 -pix_fmt yuv420p /tmp/open.mp4
rmedia clip /tmp/open.mp4 --start 1.3 --end 8.7 --mode smart --dry-run
#   smart → accurate: the video has open GOPs (frames that depend on the previous GOP)
rmedia clip /tmp/open.mp4 --start 1.3 --end 8.7 --mode smart --no-smart-fallback; echo $?
#   3
```

## Desktop

1. Open `/tmp/src.mp4`. Keyframe ticks appear every 2 s on the timeline.
2. Choose Smart and select 3.32 s to 20.72 s. The bands show head, copy and tail, with "92%
   copied".
3. Run. The result shows "Smart · 92% copied"; the file plays in the app's player.
4. Open `/tmp/open.mp4` and choose Smart. The panel says the clip will be cut in accurate mode
   and why.

## Phase 0 spikes (before the MVP)

- **S1, player compatibility** (research R5; desktop rows done 2026-11-15, `avc1` chosen; open:
  WebView2, an Android phone, an iPhone, a Reddit upload): play smart outputs (mp4 `avc3`, mp4 `avc1` with
  in-band parameter sets, mkv, ts) made from a source with different encoder settings in WebKitGTK,
  WebView2, Chrome, Firefox, VLC, an Android phone and an iPhone. Record the results in
  research.md, then set the default sample entry.
- **S2, rotation** (research R5): make a smart cut of `Rotated90` with `-display_rotation` on the
  joined input; check the displayed size in every output container.
- **S3, copy seek in ts** (research R3): `OffsetTs` and `MislabelledTs` with Kprev seeking; the
  copied frame count equals the index count.
